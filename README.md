# APDCL Electricity Bill Calculator

A Python-based electricity bill calculator that estimates electricity charges using APDCL tariff categories and slab-wise billing.

## 📌 Project Overview

This project is a command-line electricity bill calculator developed in Python. It calculates an estimated electricity bill based on the selected connection category and electricity consumption.

The project demonstrates the use of Python programming concepts such as functions, conditional statements, loops, lists, input validation, and formatted output.

## Features

- Domestic-A electricity bill calculation
- Domestic-B electricity bill calculation
- Commercial electricity bill calculation
- Slab-wise/telescopic tariff calculation
- Fixed charges
- Electricity duty calculation
- Configurable FPPPA charge
- Input validation and error handling
- Detailed bill summary

## ⚡ Tariff Categories

The calculator supports:

- **Domestic-A**
- **Domestic-B**
- **Commercial**

The tariff values used in the program are based on the APDCL FY 2026–27 tariff structure where applicable.

## 🛠️ Technologies Used

- Python 3
- Functions
- Conditional statements
- Loops
- Lists
- Exception handling
- Formatted console output
